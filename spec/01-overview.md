# Functional Documentation - Amazon Modern Widgets (AMW)

## Overview

**Amazon Modern Widgets (AMW)** is a modern and optimized solution for integrating Amazon product widgets into websites. This project provides an alternative to Amazon's standard widgets with improved user interface and optimized performance.

### Main Objectives
- Provide simplified REST APIs for integrating Amazon PAAPI 5
- Offer a collection of product widgets with asynchronous data loading
- Provide a modern and simple solution for integrating Amazon product descriptions into all types of CMS
