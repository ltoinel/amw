## CMS Integration

AMW is compatible with all popular CMS platforms:

### WordPress
```html
[iframe src="https://your-server/amazon/card?id=B084DN3XVN" width="100%" height="200"]
```

### Ghost, Joomla, Drupal
```html
<iframe src="https://your-server/amazon/card?keyword=arduino" 
        scrolling="no" frameborder="no" loading="lazy" 
        style="width:100%; height:200px;"></iframe>
```

### Direct JavaScript Integration
```html
<script src="https://your-server/amazon/widget"></script>
<div class="amazon" id="B084DN3XVN"></div>
```
