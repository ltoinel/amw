## ⚡ Quick Commands

```bash
# Documentation
npm run docs:validate        # Validate docs structure
npm run docs:list           # List all documentation

# Docker
npm run docker:dev          # Start development environment
npm run docker:test         # Run tests in containers
npm run docker:validate     # Validate Docker structure

# Testing & Quality
npm run ci:check            # Complete CI validation

npm run lint                # Code quality check

# Development
npm run dev                 # Start development server
npm run build              # Build for production
```
